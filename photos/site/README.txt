Photos for fixed spots on the pages go in this folder.

Name each photo after the spot it fills, then run the build (or push to GitHub).
The gray placeholder on each page shows the file name it wants. Homepage spots:

  home-hero.jpg        wide jobsite shot, machine grading a residential lot
  home-homeowner.jpg   finished homeowner driveway or backyard pad
  home-builder.jpg     new-construction lot with pad cut and utilities trenched
  home-driveways.jpg   regraded gravel driveway with fresh stone
  home-pads.jpg        compacted gravel pad with a shed going up
  home-drainage.jpg    French drain trench with pipe and stone
  home-site-prep.jpg   machine grading a new home lot

.jpg, .png or .webp all work. Big phone photos are fine: the build shrinks them
and removes GPS location data. Skip photos that show house numbers, license
plates or faces.
